# Logo-matched brand theme

The supplied company logo is included in `assets/company-logo.png` and displayed in the header and footer of all six pages. The original image was cropped to remove excess white margin; the artwork was not redrawn.

The shared palette uses deep ocean teal (#103F43), marine teal (#17666B), sea mist (#EDF5F4), pale teal highlights (#A6DDD5), and white. Warning notices use a separate warm neutral color. The earlier navy-and-red draft has been replaced. Existing UX improvements and responsive design are retained.

## Gallery

`gallery.html` contains the supplied 37.245-second video, hosted locally in `assets/jaliyan-video.mp4`. The source H.264 stream was copied without re-encoding and MP4 metadata moved to the beginning for progressive playback. The original has no audio stream. The player uses native controls, inline mobile playback, a poster frame, no autoplay and a direct download link. Gallery is not speculatively prerendered to avoid unnecessary media downloads.
